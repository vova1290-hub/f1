Система учёта коммерческих предложений
Назначение
Приложение предназначено для создания и учёта коммерческих предложений. Оно помогает рассчитать итоговую стоимость предложения, определить его статус и срок действия.

Целевая аудитория
Менеджеры по продажам и сотрудники небольших компаний, которые готовят коммерческие предложения для клиентов.

Предметная область
Коммерческое предложение содержит номер, сведения о клиенте, стоимость, скидку, дату создания, срок действия и статус согласования. В дальнейшем система позволит хранить предложения и следить за их обработкой.

Основные сущности
коммерческое предложение;
клиент;
товар или услуга;
менеджер.
Основные функции
расчёт итоговой суммы коммерческого предложения с учётом скидки;
определение статуса коммерческого предложения;
расчёт даты окончания действия коммерческого предложения.
Реализованный сценарий ПР1
В программе создаются исходные данные одного коммерческого предложения. После этого программа рассчитывает итоговую сумму со скидкой, определяет статус, вычисляет срок действия и выводит результат на экран.

Запуск программы
Для запуска выполните команду:

python3 main.py
